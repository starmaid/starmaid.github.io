This project was an entry to the [19th RPGMaker Horror Game Jam](https://itch.io/jam/19th-rpg-maker-horror-game-jam) where the theme was "Cursed Jewel". This was my first time making a video game, and my first time using the Unity game engine.

![gif of the game]()

## Getting Started

Mimi from ebro came to our discord server with the proposition to gather all of these talented artists and writers, and make a video game. Gamejams are a good way to get a game DONE instead of just throwing some ideas with no set goals together, and the themes and style restrictions give just enough to let artistry and ideas flow easily. E was the foremost expert, having done several gamejams with other people in university, and was willing to coach some of us through the process.

![idk maybe a discord screenshot? maybe a miro board screenshot?]()

I was super excited to work with talented artists so i was happy to take a vision backseat and focus on tools and game building. We did an ideation session, where everyone threw some ideas around, and we settled on using Unity to make a RPGMaker-style game, and some basics for the story and where the horror comes from.

## Training

This was most people's first time ever working on a video game, and some people's first time ever working on a programming project at all. As such, over a month before the start date we held short classes on how to use some various tools once a week.

- Miro canvas basics
- Unity basics
- Github and git basics
- Github project management basics
- Ink dialogue system basics

Also for a gamejam, we are allowed to do ideation and concept design before the start - so various artists worked on style tests, sketches, scene descriptions, etc. I also used some of this time to learn the differences between Unity and the only game engine I had used until then, Unreal Engine 4.

## The Jam

Then the gamejam started in earnest. We ended up ditching github in favor of miro, and just moved cards around the whiteboard there.

To make asset creation easier, I set up a google drive to git script that allowed artists to export files and have them become availible to the programmers in the same folder structure. I coupled that with a spreadsheet to track asset completion that one of the other members took and ran with to make beautiful.

It became clear that many people on the project loved the project management aspect of it. We did probably spend too much focus on the tools and process, but it was a huge learning experience. 

I set up a github action to build the game for multiple platforms, including webGL. This made builds reproducible and easy to track.

I worked on some shaders to make the game pop. I followed acerola's dithering shader for my own implementation in unity's shadergraph implemtation.

I also added a flickering glow shader for candles and electric lighting.

I made sure the downsampling filter was clean for the whole scene to give it a bit of a pixelly look. This was coordinated with canvas size rules for the artists.

Getting the text to render properly was another challenge.
