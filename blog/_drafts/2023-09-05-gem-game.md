What gamejam were we doing

We had a lot of people who want to make games, and mimi was the one who knew the most

I was super excited to work with talented artists so i was happy to take a backseat and focus on tools and game building

We started well in advance with short classes on how to use tools.

- Unity basics
- Github and git basics
- Miro canvas basics
- Github project management basics
- Ink dialogue system basics

We also did a little brainstorming on the game itself. Some themes, sketches, etc.

Then the gamejam started in earnest. We ended up ditching github in favor of miro, and just moved cards around the whiteboard there.

To make asset creation easier, I set up a google drive to git script that allowed artists to export files and have them become availible to the programmers in the same folder structure. I coupled that with a spreadsheet to track asset completion that one of the other members took and ran with to make beautiful.

It became clear that many people on the project loved the project management aspect of it. We did probably spend too much focus on the tools and process, but it was a huge learning experience. 

I set up a github action to build the game for multiple platforms, including webGL. This made builds reproducible and easy to track.

I worked on some shaders to make the game pop. I followed acerola's dithering shader for my own implementation in unity's shadergraph implemtation.

I also added a flickering glow shader for candles and electric lighting.

I made sure the downsampling filter was clean for the whole scene to give it a bit of a pixelly look. This was coordinated with canvas size rules for the artists.

Getting the text to render properly was another challenge.
